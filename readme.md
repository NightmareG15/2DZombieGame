This game is a 2D Parody of the game "Left 4 Dead 2", made by Valve in 2009.

The code (which is genuinely 100% vibecoded) was made in Python using OpenCode (Model MiMo V2.5 Free).

Libs used: PyGame, math, random, sys.

The game has Controller support (via SDL).

Plenty of bugs present, i do plan on fixing them but first i need to learn how to actually code in Python so the Vibe Code part of this is gone.
